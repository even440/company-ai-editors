# 多维表格（base）

入口 `apps/editors/base/main.tsx`，组件在这个目录：`BaseEditor.tsx`（状态、工具栏、视图页签、宿主消息）、`GridView.tsx`（表格视图，列模型用 `@tanstack/react-table` 9，行按滚动位置只画可见的一段）、`views.tsx`（看板、画廊、日历、表单）、`modals.tsx`（记录、字段、视图弹窗）、`cells.tsx`（格子的显示和编辑控件、弹出菜单）、`model.ts`（内容模型和筛选 / 排序 / 纯文本 / 一句话筛选 / 汇总，不碰 DOM）、`export.ts`（导出 Excel）。界面照原型 `prototype-v2/views-docs2.js` 的 `CAI.docEditors.base`。

## 内容格式

```jsonc
{
  "fields": [
    { "id": "f1", "name": "客户", "type": "text" },
    { "id": "f2", "name": "阶段", "type": "select", "opts": [["待跟进", "gray"], ["已签约", "green"]] }
  ],
  "records": [
    { "id": "r1", "v": { "f1": "星河科技", "f2": "已签约", "f3": "ln", "f4": "2026-10-31", "f5": 36, "f6": true, "f7": "https://…" } }
  ],
  "views": [
    { "id": "v1", "name": "表格视图", "type": "grid", "filter": { "fid": "f5", "op": "gt", "val": "30" }, "sort": { "fid": "f4", "dir": "asc" }, "hidden": ["f7"] },
    { "id": "v2", "name": "按阶段", "type": "kanban", "group": "f2" }
  ]
}
```

- 字段类型和值：`text` 字符串；`select` 选项名（`opts` 是 `[名称, 颜色]`，颜色是 base.css 里 `.c-*` 的名字：blue / green / orange / purple / teal / red / yellow / gray）；`multi` 选项名数组；`user` 成员编号（成员列表来自 `s.client.directory()`）；`date` `YYYY-MM-DD`；`number` 数字；`check` 布尔；`url` 字符串。空值是 `""`（复选框是 `false`）。
- 视图类型 `grid | kanban | gallery | calendar | form`。`group` 在看板里是分组用的单选字段，在日历里是排列用的日期字段；`filter.op` 是 `has`（包含）/ `eq`（等于）/ `gt`（大于）/ `lt`（小于）；`sort.dir` 是 `asc | desc`；`hidden` 是这个视图里隐藏的字段编号。筛选、排序、隐藏都存在视图里，切回来还在。
- `content` 为 `{}` 时初始化：名称（text）、状态（select）、负责人（user）、截止日期（date）四个字段，没有记录，一个表格视图和一个按「状态」分组的看板。
- `plain`：每条记录一行，`字段名: 值` 用空格连起来（人员显示姓名，复选框显示是 / 否，多选用「、」连）。

## 宿主消息

| 消息 | 处理 |
|---|---|
| `export`，`format: 'xlsx'` | 导出当前视图看得见的记录和字段（已筛选、已排序、未隐藏），一个工作表，文件名是标题 |
| `command` `filter`，`args` 是一句话 | 按原型 `CAI.baseNlq` 的规则解析成筛选条件并应用到当前视图（表单视图会先切到第一个列表视图）：「大于 / 超过 30」「小于 / 不到 30」用数字字段，「10 月 20 日之后」用日期字段，「负责人是李娜」或句子里出现通讯录里的名字用人员字段，出现某个选项名用那个单选 / 多选字段，「已续约的」用复选框字段，其余取句子里第一个像样的词在第一个文本字段里找包含。句子里提到了字段名就用那个字段，否则用第一个同类型的字段。解析不出就提示 |
| `command` `summary` | 统计当前视图的记录：条数、数字字段的合计 / 平均 / 最大 / 最小、单选 / 人员 / 多选的分布、复选框的勾选数、日期范围；通过 `{ type: 'selection', text }` 发回宿主 |
| `command` `addFields`，`args` 是 `[{ name, type, opts? }]` | 追加字段；`opts` 可以是名称数组或 `[名称, 颜色]` 数组，单选 / 多选没给选项时放两个占位选项 |
| `insert`，`text` 或 `html` | 新增一条记录，文字放进第一个文本字段 |
| `readonly` | 切换只读：不能改格子、字段、记录和视图，但还能切视图、筛选、排序、隐藏字段（这些改动不保存） |
| `title` | 更新表单视图顶部显示的标题 |
| `flush` | 立刻保存（会话本身也会处理） |

## 界面

- 视图页签：点击切换；点当前页签（或右键任一页签）打开重命名 / 删除；「+ 视图」新建（名称 + 类型）。
- 工具栏：筛选（筛选条：字段 / 条件 / 值）、排序（字段 + 升降序）、分组（看板）、字段（显示 / 隐藏、编辑、删除、添加）、新增记录、记录数。
- 表格：格子点一下就改（文本 / 数字 / 链接 / 日期是输入框，单选 / 多选 / 人员弹出选项面板，复选框直接切换）；列头点击或右键打开菜单（编辑字段、左右插入、升降序、按它筛选、隐藏、删除）；行号点开记录弹窗；表尾「+ 新增记录」。
- 看板：按单选字段分组，卡片可拖到别的列；画廊：卡片；日历：按日期字段排月历，可切换月份，双击某天新增那天的记录；表单：填写后成为一条新记录并回到表格视图。
- 手机宽度：页签、表格、看板都能横向滚动，工具栏只留图标。
